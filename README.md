# Label 72 — Customer Collections

Mobile-first design inspiration gallery for Label 72, Belagavi.

Customers scan a printed QR, browse blouse, kurta, lehenga and dress design concepts, save favourites and enquire via WhatsApp at +91 95911 20128.

## Publish with GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch**; choose **main** and **/(root)** and save.

Expected URL: https://aimedat-solutions.github.io/label72-collections/

For Bhindi Bazar street campaign attribution, use:
https://aimedat-solutions.github.io/label72-collections/?src=bhindi-bazar-qr

## Notes

Current designs are inspiration concepts, **not** a verified portfolio of completed Label 72 garments. Update photos with your own tailored pieces before presenting them as completed work. The site is static and does not collect or store customers' personal details; enquiries open WhatsApp.

Update `index.html` in `main` to update the public catalogue.
