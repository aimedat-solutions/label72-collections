How updates work

When you click Publish, this admin tool saves an optimized image to the GitHub repository and updates photos.json. GitHub Actions automatically republishes the collection. Do not close the tab during an upload. After the successful message, open the public gallery to check the published version.

If the upload fails, you can retry. The public gallery keeps its illustration or previously published photo until the new configuration is saved.
